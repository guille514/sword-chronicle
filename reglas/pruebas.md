# Pruebas y Dificultades

Siempre que intentes algo con consecuencias dramáticas o cuando el resultado de la acción sea incierto, realizas una **prueba** (test). Una prueba es una tirada de dados con el objetivo de alcanzar o superar la **Dificultad** de la acción.

## El Proceso de Prueba

El proceso de resolución de una prueba sigue estos pasos:

1. **El jugador declara la acción**
2. **El Narrador selecciona la habilidad** más relevante
3. **El Narrador fija la Dificultad**
4. **El jugador tira los dados** (rango de habilidad + bonificaciones)
5. **El jugador suma los dados** y aplica modificadores
6. **El jugador compara el resultado** con la Dificultad
7. **El Narrador describe el resultado**

!!! example "Ejemplo completo"
    Lady Lanara tiene Awareness 3 y Notice 2B. Quiere escuchar una conversación susurrada en la oscuridad.
    
    - **Habilidad:** Awareness
    - **Dificultad:** Formidable (12) - está oscuro y lejos
    - **Dados:** 3 dados de prueba + 2 dados de bonificación = 5 dados
    - **Resultado:** Saca 6, 6, 5, 2, 1. Descarta los dos más bajos (1 y 2) y suma los tres mejores: **17**
    - **Éxito:** 17 ≥ 12, ¡supera la prueba con 5 grados de éxito!

## Dificultades

Cada acción tiene una Dificultad, un número que describe lo difícil que es lograrla. Si tu resultado iguala o supera la Dificultad, la acción tiene éxito.

| Descripción | Dificultad | Rango Mínimo para el Éxito |
| :--- | :---: | :---: |
| **Automática** | 0 | 1 |
| **Fácil** | 3 | 1 |
| **Rutinaria** | 6 | 1 |
| **Desafiante** | 9 | 2 |
| **Formidable** | 12 | 2 |
| **Difícil** | 15 | 3 |
| **Muy Difícil** | 18 | 3 |
| **Heroica** | 21+ | 4 |

!!! tip "Consejo para el Narrador"
    Si tienes dudas sobre qué dificultad poner, **lo normal es que sea Desafiante (9)**. Es el punto dulce donde personajes competentes suelen tener éxito pero aún hay tensión.

## Grados de Éxito y Fracaso

No basta con superar la Dificultad; el **margen** por el que la superas (o fallas) importa.

| Diferencia entre Resultado y Dificultad | Grado de Éxito/Fracaso |
| :---: | :--- |
| -5 o menor | **Fracaso crítico** |
| -1 a -4 | **Fracaso marginal** |
| 0 a +4 | **Éxito marginal** |
| +5 a +9 | **Gran éxito** |
| +10 a +14 | **Éxito increíble** |
| +15 o más | **Éxito asombroso** |

### Éxito

Cuando el resultado iguala o supera la Dificultad, la acción tiene éxito. Un éxito representa el mínimo de trabajo y esfuerzo necesario para lograr el resultado deseado. Estos éxitos suelen ser torpes e inelegantes, y aunque te permiten lograr lo que querías, no son impresionantes.

### Fracaso

Una prueba fallida simplemente significa que la acción intentada no funciona, pero generalmente no significa que no puedas volver a intentarlo. En algunas situaciones, el fracaso puede conllevar un mayor riesgo, como una prueba de Athletics fallida para escalar un muro o una prueba de Agility fallida para mantener el equilibrio en una superficie resbaladiza.

!!! warning "Fracaso Crítico"
    Siempre que haya peligro involucrado y falles la prueba por **5 o más**, puedes sufrir un **Fracaso Crítico**: consecuencias adicionales en forma de daño, lesión u otro inconveniente, generalmente especificado en la acción intentada.

## Tipos de Prueba

### Prueba Básica

La prueba básica es la predeterminada para casi todas las acciones. Si el juego o la situación no indica otro tipo de prueba, usa una prueba básica.

1. Tira dados de prueba iguales al rango de habilidad
2. Tira dados de bonificación de Especialidad o Asistencia
3. Descarta un número de dados igual a los dados de bonificación tirados, y suma el resto
4. Suma o resta cualquier modificador
5. Compara el Resultado con la Dificultad para determinar éxito o fracaso

### Prueba Básica Extendida

Algunas acciones son tan complejas o ambiciosas que requieren múltiples pruebas para determinar el éxito. Un personaje escalando un acantilado empinado puede tener que probar Athletics varias veces para llegar a la cima. Cuando la situación lo exija, el Narrador puede informarte que necesitas dos o más éxitos para completar tu acción.

### Prueba de Competición

Las pruebas de competición ocurren cuando dos personajes trabajan hacia o compiten por el mismo objetivo. Ambos personajes tiran pruebas contra la misma Dificultad. El personaje que supere la Dificultad por el mayor margen gana.

!!! example "Ejemplo"
    Chris y Hal están en una carrera a pie. Ambos eventualmente cruzarán la meta, pero compiten para ver quién llega primero. El Narrador pide pruebas de competición de Athletics Automática (0).
    
    - **Chris** (Athletics 3): Saca 6, 4, 1 = **11**
    - **Hal** (Athletics 2, Run 1B): Saca 5, 2, 2. Descarta un 2 por el dado de bonificación = **7**
    
    Chris gana la carrera.

### Prueba de Conflicto

Las pruebas de conflicto se usan más comúnmente en combate, guerra e intriga. Una prueba de conflicto siempre se usa para resolver cualquier cosa que funcione como un "ataque". A diferencia de una prueba básica, donde pruebas contra el desafío de la acción, una prueba de conflicto enfrenta tu habilidad directamente contra tu oponente.

La Dificultad de estas pruebas es la **Defensa** de tu oponente.

## Modificadores de Pruebas

### Modificadores

Un modificador es un número fijo que se suma al resultado de tu prueba para reflejar circunstancias favorables, o se resta para reflejar circunstancias desfavorables. La mayoría de los modificadores provienen de asistencia, condiciones ambientales o lesiones.

### Asistencia

Cuando te enfrentas a una Dificultad difícil, puedes pedir ayuda a tus aliados. Cualquier aliado adyacente puede asistirte. Los aliados otorgan un modificador al resultado de tu prueba igual a **la mitad de su rango en la habilidad** que estás probando (redondeado hacia abajo, mínimo 1).

!!! example "Ejemplo"
    Estás escalando un muro. Estás cerca de la cima, donde tu aliado espera. Para ayudarte, un aliado con Athletics 4 te asiste. Cuando pruebas Athletics para escalar el resto de la distancia, sumas **+2** (la mitad del rango de tu aliado) al resultado de tu prueba.

    Normalmente, no más de dos personas pueden asistir a la vez, pero para tareas más grandes, el Narrador puede permitir asistencia adicional.

### Tomarse Más Tiempo

Cuando tienes el lujo del tiempo de tu lado, puedes trabajar más lentamente para asegurarte de completar la tarea. Por cada cantidad adicional de tiempo gastada preparándote para la tarea, ganas un **dado de prueba extra**. No puedes ganar más del doble de tus dados de prueba de esta manera.

### Especialidades y Dados de Bonificación

Las especialidades son áreas de experiencia que caen bajo la jurisdicción de una habilidad. Cuando pruebas una habilidad de una manera que se relaciona con tu especialidad, puedes tirar un número de **dados de bonificación** igual a tu rango en la especialidad.

Los dados de bonificación **nunca se suman al resultado**; simplemente te permiten tirar más dados y quedarte con los mejores. El número de dados de bonificación nunca puede exceder el número de dados de prueba tirados.

!!! example "Ejemplo"
    Shane's character, Trent, tiene Stealth 3 (Blend In 2B). Cuando intenta mezclarse con una multitud, tira **cinco dados** y se queda con los **tres mejores** tirados.

## Fallo y Dados de Penalización

Los dados de penalización son desventajas poco comunes impuestas por heridas o defectos. Cada dado de penalización cancela un dado de prueba al sumar tu resultado. Aplicas los dados de penalización después de tirar y después de descartar cualquier dado de bonificación.

!!! example "Ejemplo"
    Steve's character, Rann, sufre una herida que impone 1 dado de penalización en todas las pruebas. En medio del combate, dispara una flecha con su arco largo a un bandido que carga. Tiene Marksmanship 4 (Bows 2B).
    
    - Tira seis dados: 6, 5, 4, 4, 3, 1
    - Descarta el 1 y el 3 por sus dados de bonificación
    - **Debe descartar también uno de sus 4s** por el dado de penalización
    - Resultado final de la prueba: **15**

## Lesiones y Frustración

Participar en combate e intriga te pone en riesgo de sufrir lesiones o adquirir frustración. Ambos afectan tu capacidad para tener éxito en las pruebas, imponiendo una penalización al resultado de tu prueba o, en el caso de heridas, tomando dados de penalización de tu tirada de dados.
