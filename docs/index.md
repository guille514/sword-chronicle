   # ⚔️ Sword Chronicle

   ## Manual de Rol - Feudal Fantasy Roleplaying

   Bienvenido al manual online de **Sword Chronicle**, un juego de rol de fantasía feudal donde los jugadores toman el papel de miembros de una casa noble.

   !!! info "¿Cómo usar este manual?"
       Usa el **menú lateral** para navegar por los capítulos. El **buscador** (lupa arriba a la derecha) te permite encontrar cualquier regla al instante.
