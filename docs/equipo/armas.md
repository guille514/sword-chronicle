# ⚔️ Armas

Los grandes caballeros y nobles llevan armas de la más alta calidad. Sin embargo, para bandidos y campesinos desesperados, lo único que importa es que el herramienta sea efectiva para infligir o defenderse del daño.

---

## 🏅 Calidad del Arma

Existen cuatro categorías de calidad, que funcionan como cualidades del arma:

| Calidad | Modificadores | Descripción |
|:--------|:--------------|:------------|
| 🔴 **Pobre** | –1D en pruebas de Lucha o Puntería | Usada por comunes reclutados, hombres rotos o bandidos. Ej: una hoz oxidada. |
| ⚪ **Común** | Ninguno | Producida por herreros de habilidad común. Usada por guardias urbanos y soldados. |
| 🔵 **Superior** | +1 al resultado de todas las pruebas de Lucha o Puntería | Forjada por maestros herreros con materiales de alta calidad ("forjada en castillo"). |
| 🟡 **Extraordinaria** | Como Superior, +1 al daño base del arma | Forjada con acero exótico (ej. acero de Damasco). Solo unos pocos herreros en el mundo conocen el secreto. |

## 📖 Cualidades de las Armas

| Cualidad | Descripción |
|:---------|:------------|
| 🔄 **Adaptable** | Diseñada para usarse con una o dos manos. Si se usa con dos manos, aumenta el daño base en +1. |
| 📦 **Voluminoso** | Reduce tu Movimiento. Apunta hacia el total de "Volumen" (Bulk) del personaje. |
| 🎯 **Corto Alcance** | Alcance efectivo de 10 yardas. –1D por cada 10 yardas adicionales. |
| 🛡️ **Defensivo** | Si no atacas con ella, añade su bono defensivo a tu Defensa de Combate. |
| 🕸️ **Enredante** | Al golpear, el objetivo reduce su Movimiento a 1 yarda y sufre –5 en todas las pruebas hasta que supere una prueba de Agilidad o Atletismo (Dificultad 9). |
| ⚡ **Rápido** | Al realizar un Ataque Dividido, ganas +1B en cada prueba. |
| 🤝 **Agarre** | Si golpeas y superas el resultado pasivo de Atletismo del oponente, puedes agarrarlo. El oponente agarrado no puede moverse y su Defensa de Combate baja en 5 (mínimo 1). |
| 📌 **Empalar** | Con 3+ grados de éxito, clavas el arma. Debes superar una prueba de Agilidad (9) o quedas desarmado. El objetivo no puede moverse. |
| 🏹 **Largo Alcance** | Puedes atacar hasta 100 yardas. –1D por cada 100 yardas de distancia. |
| 🐎 **De Montura** | Demasiado grande para usarse a pie (–2D si se usa a pie). |
| 🗡️ **Mano secundaria** | Puede usarse en la mano no dominante. Si atacas con ambas armas, añade su modificador al daño del arma principal. |
| 💥 **Perforante** | Ignora una cantidad de RA (Armadura) igual al valor indicado. |
| 💪 **Poderoso** | Por cada dado de bonificación en la especialidad *Fuerza*, aumenta el daño del arma en +1. |
| 📏 **Alcance** | Puedes atacar a oponentes hasta 3 yardas de distancia. Atacar a alguien dentro de 1 yarda impone –1D. |
| 🔄 **Recarga** | Requiere una Acción Menor o Mayor para recargar después de disparar. |
| 🐎 **Solo para Carga** | Solo funciona con la acción de Contraataque cuando el oponente carga. |
| 💥 **Demoledor** | Con 2+ grados de éxito, reduce el Bono Defensivo o la RA del oponente en el valor indicado. Si llega a 0, el objeto se destruye. |
| 🐢 **Lento** | No puedes realizar Ataques Divididos con esta arma. |
| 😵 **Aturdidor** | Con 2+ grados de éxito, puedes sacrificar un grado para impedir que el objetivo realice una Acción Mayor en su próximo turno. |
| 🤲 **A dos manos** | Requiere ambas manos. Si se usa con una, –2D en la prueba. |
| 🐘 **Engorroso** | No puede usarse mientras se está montado (–2D en pruebas de Puntería). |
| ☠️ **Vicioso** | Si derrotas a un enemigo con esta arma, la consecuencia de la derrota es siempre la muerte (a menos que quemen un Punto de Destino). |
