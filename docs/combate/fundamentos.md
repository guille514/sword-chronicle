# ⚔️ Fundamentos del Combate

El combate en *Sword Chronicle* es peligroso, dramático y letal. A diferencia de otros juegos, aquí las palabras pueden ser tan poderosas como las armas, pero cuando se desenvainan las espadas, las consecuencias son graves.

---

## ⏱️ Rondas, Turnos y Acciones

El combate se divide en **rondas**. Cada ronda representa aproximadamente **6 segundos** de tiempo de juego. Durante una ronda, cada combatiente tiene un **turno** para actuar, en orden de iniciativa.

En tu turno, puedes realizar combinaciones de los siguientes tipos de acciones:

| Tipo de Acción | Descripción | Ejemplos |
|:---------------|:------------|:---------|
| 🟢 **Acción Gratuita** | Consume muy poco tiempo. Puedes realizar tantas como el Narrador considere razonables. | Hablar, soltar un objeto, desenvainar un arma. |
| 🟡 **Acción Menor** | Consume unos 3 segundos. Puedes realizar **hasta dos** por turno. | Moverte, apuntar, recargar un arma, levantarte del suelo. |
| 🔴 **Acción Mayor** | Consume los 6 segundos completos de tu turno. Solo puedes realizar **una** por turno (o combinar dos Menores). | Atacar, esquivar, cargar, derribar a un oponente. |

## 📊 Estadísticas de Combate

Varias habilidades definen tu eficacia en el campo de batalla. De ellas se derivan tus estadísticas defensivas y de salud.

| Habilidad | Uso en Combate |
|:----------|:---------------|
| 🤸 **Agilidad** | Se suma a tu Defensa de Combate. Determina el orden de iniciativa. Define el daño base de muchas armas a distancia. |
| 🏃 **Atletismo** | Se suma a tu Defensa de Combate. Define el daño base de la mayoría de armas cuerpo a cuerpo. |
| 👁️ **Alerta** | Se suma a tu Defensa de Combate. Te permite notar enemigos ocultos. |
| 🛡️ **Resistencia** | Determina tu **Salud** (3 × Resistencia) y el máximo de Lesiones y Heridas que puedes soportar. |
| ⚔️ **Lucha** | Se usa para atacar con armas cuerpo a cuerpo o desarmado. |
| 🏹 **Puntería** | Se usa para atacar con armas a distancia. |
| ⚔️ **Guerra** | Permite obtener ventajas tácticas y dirigir tropas. |

### 🛡️ Defensa de Combate
Es tu primera línea de defensa. Combina tu destreza, condición física y percepción.
**Defensa de Combate = Agilidad + Atletismo + Alerta + Bono Defensivo** (de escudos o armas de parada).

### ❤️ Salud
Tu capacidad para absorber daño y seguir luchando. Mientras tengas al menos 1 punto de Salud, tus habilidades no se reducen.
**Salud = 3 × Resistencia**

### 👟 Movimiento
Describe cuántas yardas te mueves al usar una acción de movimiento. El movimiento base es de **4 yardas**.
- **Efectos de Atletismo:** Por cada 2 dados de bonificación en la especialidad *Correr*, tu movimiento aumenta en 1 yarda. Si tienes rango 1 en Atletismo, tu movimiento se reduce a 3 yardas (a menos que tengas bonos en *Correr*).
- **Efectos del Volumen:** El equipo voluminoso (como armaduras pesadas) reduce tu movimiento en la mitad de sus puntos de Volumen, y tu velocidad de esprint en 1 yarda por cada punto de Volumen.

## 🛡️ Armaduras

La armadura ofrece protección, pero a un coste en movilidad. Todas las armaduras tienen tres estadísticas:

| Estadística | Descripción |
|:------------|:------------|
| **RA (Rating de Armadura)** | Reduce el daño recibido. El daño no puede reducirse por debajo de 0. |
| **Penalización** | Se resta a **todas** las pruebas de Agilidad. No reduce tu Defensa de Combate, pero sí tu capacidad para realizar acrobacias o escapar. |
| **Volumen** | Cada 2 puntos de Volumen reducen tu Movimiento en 1 yarda, y cada punto reduce tu velocidad de esprint en 1 yarda. |

!!! info "ℹ️ Armaduras de Montura (Barda)"
    La barda para caballos pesa el doble y cuesta cuatro veces más que la armadura humana (la mitad para ponis). Debe quitarse por la noche.

## ⚔️ Armas y Cualidades

Las armas no son solo herramientas; son extensiones de tu entrenamiento. Cada arma tiene una **Especialidad** (que otorga dados de bonificación), un requisito de **Entrenamiento** (si no lo tienes, pierdes dados de bonificación o ganas dados de penalización), y un **Daño** base (tu rango en la habilidad clave ± modificadores, multiplicado por los grados de éxito).

### Cualidades de las Armas
| Cualidad | Descripción |
|:---------|:------------|
| 🔄 **Adaptable** | Puede usarse con una o dos manos. Con dos manos, el daño base aumenta en +1. |
| 📦 **Voluminoso** | Aplica puntos de Volumen que reducen tu Movimiento. |
| 🎯 **Corto Alcance** | Alcance efectivo de 10 yardas. –1D por cada 10 yardas adicionales. |
| 🛡️ **Defensivo** | Si no atacas con ella, añade su bono a tu Defensa de Combate. |
| 🕸️ **Enredante** | Al golpear, el objetivo reduce su Movimiento a 1 yarda y sufre –5 en todas las pruebas hasta que supere una prueba de Agilidad o Atletismo (Dificultad 9). |
| ⚡ **Rápido** | Al realizar un Ataque Dividido, ganas +1B en cada prueba. |
| 🤝 **Agarre** | Si golpeas y superas el resultado pasivo de Atletismo del oponente, puedes agarrarlo. El oponente agarrado no puede moverse y su Defensa de Combate baja en 5 (mínimo 1). |
| 📌 **Empalar** | Con 3+ grados de éxito, clavas el arma. Debes superar una prueba de Agilidad (9) o quedas desarmado. El objetivo no puede moverse. |
| 🏹 **Largo Alcance** | Puedes atacar hasta 100 yardas. –1D por cada 100 yardas de distancia. |
| 🐎 **De Montura** | Demasiado grande para usarse a pie (–2D si se usa a pie). |
| 🗡️ **Mano secundaria** | Puede usarse en la mano no dominante. Si atacas con ambas armas, añade su modificador al daño del arma principal. |
| 💥 **Perforante** | Ignora una cantidad de RA igual al valor indicado. |
| 💪 **Poderoso** | Por cada dado de bonificación en la especialidad *Fuerza*, aumenta el daño del arma en +1. |
| 📏 **Alcance** | Puedes atacar a oponentes hasta 3 yardas de distancia. Atacar a alguien dentro de 1 yarda impone –1D. |
| 🔄 **Recarga** | Requiere una Acción Menor o Mayor para recargar después de disparar. |
| 🐎 **Solo para Carga** | Solo funciona con la acción de Contraataque cuando el oponente carga. |
| 💥 **Demoledor** | Con 2+ grados de éxito, reduce el Bono Defensivo o la RA del oponente en el valor indicado. Si llega a 0, el objeto se destruye. |
| 🐢 **Lento** | No puedes realizar Ataques Divididos con esta arma. |
| 😵 **Aturdidor** | Con 2+ grados de éxito, puedes sacrificar un grado para impedir que el objetivo realice una Acción Mayor en su próximo turno. |
| 🤲 **A dos manos** | Requiere ambas manos. Si se usa con una, –2D en la prueba. |
| 🐘 **Engorroso** | No puede usarse mientras se está montado (–2D en pruebas de Puntería). |
| ☠️ **Vicioso** | Si derrotas a un enemigo con esta arma, la consecuencia de la derrota es siempre la muerte (a menos que quemen un Punto de terbakino). |
