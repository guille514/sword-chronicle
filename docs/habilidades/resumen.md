# 📊 Resumen de Habilidades

Sword Chronicle tiene **18 habilidades** que representan las capacidades básicas de los personajes. Cada habilidad puede tener **especialidades** que otorgan dados de bonificación.

---

## 🎯 Tabla Rápida de Habilidades

| Habilidad | Descripción |
|:----------|:------------|
| 🏃 **Atletismo** | Correr, saltar, escalar, nadar, fuerza bruta |
| 🐎 **Manejo de Animales** | Montar, entrenar, calmar animales |
| 👁️ **Alerta** | Notar detalles, detectar peligros, empatía |
| 🧠 **Astucia** | Inteligencia, lógica, descifrar, memoria |
| 🎭 **Engaño** | Mentir, disfrazarse, hacer trampa, actuar |
| 🛡️ **Resistencia** | Salud, aguante, resistir venenos y enfermedades |
| ⚔️ **Lucha** | Combate cuerpo a cuerpo con armas |
| 💊 **Curación** | Medicina, primeros auxilios, tratar heridas |
| 📚 **Conocimiento** | Cultura general, investigación, callejeo |
| 🗣️ **Idioma** | Comunicarse, leer, escribir, elocuencia |
| 🏹 **Puntería** | Armas a distancia (arcos, ballestas, arrojadizas) |

## 📈 Rangos de Habilidad

Los rangos van de **1 a 7** y representan el nivel de competencia:

| Rango | Nivel | Descripción |
|:-----:|:------|:------------|
| 1 | 🟢 **Novato** | Conocimientos básicos |
| 2 | 🟡 **Competente** | Nivel promedio |
| 3 | 🔵 **Experto** | Profesional |
| 4 | 🟣 **Maestro** | Muy hábil |
| 5 | 🟠 **Virtuoso** | Excepcional |
| 6 | 🔴 **Élite** | Entre los mejores |
| 7 | ⚫ **Legendario** | Sin igual en el mundo |

---

## 🎲 Dados de Bonificación (Especialidades)

Las especialidades otorgan **dados de bonificación** cuando usas la habilidad en un contexto específico.

!!! example "📜 Ejemplo"
    Un personaje con **Lucha 3 (Espadas Largas 2B)** tira:
    
    - **5 dados** en total (3 de habilidad + 2 de bonificación)
    - Se queda con los **3 mejores** resultados
    
    Cuando usa una espada larga, tiene ventaja. Con otras armas, solo tira 3 dados.

---

## 💡 Consejos para Elegir Habilidades

!!! tip "🎯 Para Principiantes"
    - **Luchadores**: Prioriza Lucha, Atletismo, Alerta
    - **Conspiradores**: Prioriza Persuasión, Engaño, Estatus
    - **Exploradores**: Prioriza Sigilo, Atletismo, Supervivencia, Alerta
    - **Sabios**: Prioriza Conocimiento, Curación, Astucia

!!! warning "⚠️ Errores Comunes"
    - No maximices una sola habilidad (es muy caro)
    - Ten al menos 2-3 habilidades en rango 3+
    - No olvides Alerta (¡es crucial para no ser sorprendido!)
    - Estatus es importante para personajes nobles
