# 📖 Glosario de Términos del Juego

Términos clave usados en Sword Chronicle, organizados alfabéticamente para fácil referencia.

---

## A

### Habilidad (Ability)
Uno de los rasgos definitorios del juego de un personaje. Las habilidades se miden por rango.

### Prueba de Habilidad (Ability Test)
Usar una habilidad para intentar una acción cuando el resultado está en duda. Una prueba implica tirar un número de dados de seis caras (dados de prueba) igual al rango de la habilidad probada y sumarlos.

### Beneficio (Benefit)
Una cualidad de personaje con un efecto beneficioso, como un talento o conexión con personas importantes.

### Dado de Bonificación (Bonus Die)
Un dado extra tirado durante una prueba de habilidad, pero luego se descarta un número de dados bajos igual al número de dados de bonificación tirados antes de sumar los dados restantes. Los dados de bonificación se abrevian +#B, donde # es el número de dados de bonificación.

---

## D

### Daño (Damage)
Puntos imaginarios usados para rastrear qué tan cerca está un personaje de ser derrotado en combate.

### Grado (Degree)
Qué tan exitosa es una prueba de habilidad, más allá del mero éxito o fracaso.

### Puntos de Destino (Destiny Points)
El potencial del personaje (y en algunas crónicas, su conexión con fuerzas que tuercen el destino), usado por los jugadores durante el juego para influir en el destino y los resultados donde ese personaje está involucrado.

### Dados (Dice)
Aleatorizadores usados para determinar los resultados de eventos inciertos en el juego. Sword Chronicle usa dados de seis caras, a veces abreviados "d6".

### Dificultad (Difficulty)
Un valor numérico usado para medir las posibilidades de lograr un resultado particular en una prueba de habilidad. Las dificultades van desde Automática (0) hasta Heroica (21 y superior).

### Defecto (Drawback)
Una cualidad de personaje con un efecto negativo, como una discapacidad.

---

## F

### Frustración (Frustration)
Una dificultad social menor sufrida por un personaje para evitar la influencia (y por lo tanto la derrota) durante una intriga.

---

## I

### Influencia (Influence)
Puntos imaginarios usados para rastrear qué tan cerca está un personaje de ser derrotado en una intriga social.

### Lesión (Injury)
Una herida menor sufrida por un personaje para evitar daño (y por lo tanto derrota) en combate.

---

## M

### Modificador (Modifier)
Un bono o penalización que se aplica al resultado de una prueba de habilidad, expresado como +# o –#.

---

## P

### Dado de Penalización (Penalty Die)
Un dado restado de los dados de prueba (comenzando por el más bajo primero) después de que cualquier dado de bonificación haya sido descartado pero antes de que los dados se sumen para determinar el resultado. Un dado de penalización se abrevia –#D, donde # es el número de dados de penalización.

---

## C

### Cualidad (Quality)
Un rasgo que describe algún talento, habilidad o elemento de trasfondo. Los beneficiosos se llaman Beneficios; los perjudiciales se llaman Defectos.

---

## R

### Rango (Rank)
Una medida de la habilidad de un personaje, que va de 1 (deteriorado) a 7 (legendario). Las habilidades tienen un rango promedio de 2 por defecto.

### Resultado (Result)
El valor al que se llega sumando todos los dados de prueba tirados para una prueba de habilidad.

---

## P

### Prueba (Test)
Una tirada de dados para determinar el resultado de una acción donde el resultado está en duda.

### Dado de Prueba (Test Die)
Un dado que se tira y suma como parte de una prueba de habilidad. Los dados de prueba se abrevian #D, donde # es el número de dados (por ejemplo, 3D son tres dados de prueba). Dados de prueba adicionales se abrevian +#D (por ejemplo, +2D significa "añade dos dados de prueba a la prueba").

---

## H

### Herida (Wound)
Una lesión grave y duradera sufrida por un personaje para ayudar a evitar daño (y por lo tanto derrota) en combate.
